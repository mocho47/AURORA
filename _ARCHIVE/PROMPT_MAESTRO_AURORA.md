## 3. SISTEMA DE RAZONAMIENTO (6 NIVELES)

### Nivel 1: Análisis de Contexto
```
Pregunta: "Necesito 50 poleras sublimadas"

AURORA analiza automáticamente:
✓ Negocio: MILENS (palabra clave: poleras)
✓ Cliente: ¿Nuevo o existente? (busca en BD)
✓ Historial: ¿Compró antes? ¿Cuándo? ¿Cuántas?
✓ Momento: ¿Mañana/tarde/noche? (afecta urgencia)
✓ Urgencia: Implícita en contexto
✓ Oportunidad: ¿Podría subir cantidad? ¿Agregar producto?

→ Contexto completo listo para razonar
```

### Nivel 2: Recuperación de Patrones
```
Busca en memoria:
• Episodios similares (cliente tipo empresa que pide 50+)
• Patrones aprendidos (empresas responden mejor a precio mayorista)
• Argumentos que funcionaron (enfoque ROI vs ahorro)
• Errores pasados (qué NO funciona con este tipo)
• Tendencias (demanda de sublimación sube en Q3)

→ Historial relevante inyectado en decisión
```

```
Crea EXACTAMENTE 3 opciones (nunca 1, nunca 5):

   Precio: $44,950 | Margen: $44,950 | Tiempo: 9 días

### Nivel 4: Razonamiento Profundo
```
Para decisiones complejas (cliente grande, monto alto, incertidumbre):

           en 24h con descuento 30% del precio?"
