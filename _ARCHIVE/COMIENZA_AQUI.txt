SI ALGO FALLA
================================================================================

Python no encontrado:
  → Instala Python 3.9+ desde https://python.org
  → Marca "Add to PATH"

API key invalida:
  → Verifica clave en https://console.groq.com/keys
  → Copia sin espacios

Todos los SDKs fallaron:
  → Instala Ollama: https://ollama.ai
  → ollama pull dolphin-mixtral:latest

Puerto 8000 ocupado:
  → Mata proceso: netstat -ano | findstr :8000
  → taskkill /PID <numero> /F
