================================================================================
                    TROUBLESHOOTING RAPIDO
================================================================================

"No funciona nada"
  -> Ejecuta: .\LAUNCHER_AURORA.ps1 -Test
  -> Verifica: 6/6 tests deben pasar

"API key invalida"
  -> Copia exactamente de console
  -> Sin espacios al inicio/final
  -> Reinicia PowerShell

"Puerto 8000 ocupado"
  -> netstat -ano | findstr :8000
  -> taskkill /PID xxx /F

"No reconoce motores"
  -> Verifica: metadata.json existe
  -> Verifica: motor_xxx.py en MOTORES/
  -> Ejecuta tests

"Respuestas lentas"
  -> Aumenta timeouts en config.py
  -> Configura API key rapida (Groq)
  -> Usa Ollama local si necesitas velocidad

Ver mas: PRIMER_ARRANQUE.md -> Troubleshooting
