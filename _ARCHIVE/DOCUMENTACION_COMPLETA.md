## 🔄 Flujos de Automatización

### Flujo 1: Venta ATF (Automatización Venta)
```
Cliente pregunta → Captura datos → Análisis necesidad
       ↓
Genera cotización → Envía email/WhatsApp → Seguimiento
       ↓
Confirmación → Crea pedido → Dashboard actualiza
```

### Flujo 2: Marketing MILENS (Contenido Automático)
```
Idea contenido → Script generado → Imagen creada
       ↓
Caption viral → Publica 4 redes → Monitorea engagement
       ↓
Análisis ROI → Optimiza próximo ciclo
```

### Flujo 3: Sleep Cycle (Consolidación 24h)
```
Carga episodios → Analiza patrones → Genera nuevas reglas
       ↓
Optimiza motores → Genera reporte → Persiste cambios
       ↓
Próxima ejecución en 24h
```

```bash

# Cambiar puerto en aurora_unified_main.py línea 311
```

**Problema**: APIs sin respuesta
- Verificar GROQ_API_KEY en .env
- Verificar CLAUDE_API_KEY en .env
