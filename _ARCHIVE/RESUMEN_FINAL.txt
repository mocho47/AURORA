INTELIGENCIA INCORPORADA
================================================================================

6-Tier Decision Engine:
  Tier 1: Detecta riesgo vital (usa local Ollama)
  Tier 2: Detecta emociones (enriquece contexto)
  Tier 3: Carga historial (refina analisis)
  Tier 4: Matchea patrones (elige motor)
  Tier 5: Detecta perfil (ajusta tono)
  Tier 6: Elige SDK (fallback automatico)

Motor Routing:
  "código" → motor_code_gen (Claude)
  "familia" → motor_coaching (Groq)
  "venta" → motor_ventas (Groq)
  "marketing" → motor_marketing (Zai)
  "estrategia" → motor_reasoning (Claude)
  otro → motor_analisis (default)

SDK Fallback:
  Preferido → Groq → Zai → Ollama
